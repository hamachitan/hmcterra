# Security Policy

This project shall be treated as part of [Terra](https://terrapkg.com/).
In general, the policy listed in [the repository SECURITY.txt](https://github.com/terrapkg/packages/blob/frawhide/SECURITY.md)
also applies here.

## Reporting a Vulnerability

Report via any of the following methods:
- Private vulnerability reporting is enabled for this repository: https://github.com/hamachitan/hmcterra/security/advisories
- You may also email to [security@fyralabs.com](mailto:security@fyralabs.com)
- If urgent, [join the Discord server](fyralabs.com/discord) and notify staff
